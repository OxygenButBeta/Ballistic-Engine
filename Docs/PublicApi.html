The Ballistic scripting API

Everything the engine exposes to game code. Write .cs files anywhere under your project's Assets/ folder — the engine compiles, hot-reloads, and wires them into scenes and the editor with zero boilerplate. The surface deliberately mirrors Unity, so most knowledge transfers directly.

C# · .NET 9 Math: OpenTK.Mathematics Input: GLFW key enums Hot reload: on focus / Ctrl+R

Overview

A game script is a class that derives from Behaviour (a per-entity component, like Unity's MonoBehaviour) or SceneBehaviour (a scene-wide component). Override lifecycle hooks to run your logic.

ⓘ
Cross-assembly override rule. The engine declares lifecycle hooks as protected internal virtual, but in game assemblies you must override them as plain protected (Tick, OnBegin, OnCollisionEnter, …). C# does not allow protected internal overrides across assemblies. The signatures below show the override form you should write.

Your first script

Right-click in the Asset Browser → New Script. It auto-compiles. Drag the resulting .cs tile onto a Hierarchy entity to add it as a component.

using BallisticEngine;
using OpenTK.Mathematics;
using OpenTK.Windowing.GraphicsLibraryFramework;

public class Spinner : Behaviour {
    // Public fields show up in the Inspector and serialize into the scene automatically.
    public float DegreesPerSecond = 90f;

    // Runs once, the first time this component becomes active in play mode.
    protected override void OnBegin() {
        Debug.Log("Spinner started on " + Entity.Name);
    }

    // Runs every frame during play. `delta` is seconds since last frame.
    protected override void Tick(in float delta) {
        if (Input.IsKeyDown(Keys.Space)) return;
        transform.Rotation *= Quaternion.FromEulerAngles(0f, MathHelper.DegreesToRadians(DegreesPerSecond * delta), 0f);
    }
}
⚠
Live reload, unlike Unity. Editing scripts and alt-tabbing back recompiles without stopping play. On compile errors, nothing changes (errors appear in the Console). The Play button is disabled while scripts don't compile.

Core base classes

class Behaviour : Component

Base
Engine/BObject/Objects/Behaviour.cs
The base class for per-entity game components — Unity's MonoBehaviour. Derive from it, override the lifecycle hooks you need, and add public fields for inspectable, serialized state.
bool IsEnabled { get; set; }Master enable switch. Toggling in play mode fires OnEnabled/OnDisabled lifecycle.
bool IsActive getTrue when enabled and the entity is active all the way up the hierarchy (Unity's activeInHierarchy).
Entity Entity getThe owning entity (Unity's gameObject).
Transform transform getShortcut to Entity.transform.
Lifecycle hooks — override as protected
protected void OnBegin()Fires once, the first time the component becomes active in play mode (Unity's Start).
protected void OnAttach()Fires when added to an entity, in both edit and play mode. Put render/registration here, never in OnEnabled.
protected void OnDetach()Fires when removed from an entity or the scene tears down.
protected void OnEnabled()Play-mode only. Fires whenever the component becomes active. May fire multiple times.
protected void OnDisabled()Play-mode only. Fires when the component becomes inactive.
protected void Tick(in float delta)Per-frame update during play (Unity's Update). delta = seconds since last frame.
protected void FixedTick(in float delta)Fixed 60 Hz physics update (Unity's FixedUpdate). Apply forces here.
Contact callbacks — play mode, override as protected
protected void OnCollisionEnter(Collision c)Two solid bodies start touching. Also OnCollisionStay / OnCollisionExit.
protected void OnTriggerEnter(Collider other)A body enters a trigger collider. Also OnTriggerStay / OnTriggerExit.
Component lookup (forward to the entity)
T GetComponent<T>()First component of type T on the same entity. Also TryGetComponent, GetComponents.
T GetComponentInChildren<T>(bool includeInactive)Search this entity and its descendants. GetComponentInParent searches ancestors.
T AddComponent<T>()Add a new component to the same entity.
Coroutines & gizmos
CoroutineHandle StartCoroutine(IEnumerator<IYieldInstruction>)Start a classic coroutine. StopCoroutine(handle) stops it. (See also the async API.)
public void OnDrawGizmos(IGizmos g)Editor scene-view drawing. OnDrawGizmosSelected runs only for the selected entity. No-op at runtime.

Physics

BepuPhysics 2 behind a facade. Bodies exist in play mode only and step at a fixed 60 Hz. Add a Rigidbody for a simulated body; add colliders for shapes (a collider with no rigidbody becomes static level geometry).

class Rigidbody : Behaviour

Engine/Physics/Rigidbody.cs
Makes an entity physically simulated. A dynamic body owns its transform during play — move it with Velocity/AddForce, not by writing the transform (that teleports it).
float Mass { get; set; }Mass in kg (default 1).

void AddImpulse(Vector3) · AddImpulseAtPosition(...) · AddAngularImpulse(...)Instantaneous impulses (kg·m/s). The "AtPosition" variant induces rotation.
void Teleport(Vector3 pos, Quaternion rot)Instantly move a dynamic body without an interpolated sweep.

Post-processing volumes

A Unity-style volume framework. A Volume component contributes a VolumeProfile (a .volume asset) into a blended stack. To add a new effect, subclass VolumeComponent with public VolumeParameter fields — no other wiring.

class Volume : Behaviour

Engine/Rendering/Volumes/Volume.cs
Blends a profile of post-process overrides into the frame — global, or local inside a box.
bool IsGlobal · float Priority · WeightGlobal = everywhere; local = inside the box. Higher priority wins; weight is 0..1 master strength.
float BlendDistance · Vector3 BoxSizeFade distance outside a local box, and the box size (scaled by the transform).
VolumeProfile ProfileThe shared .volume asset of overrides.

class VolumeComponent · VolumeParameter

Engine/Rendering/Volumes/VolumeComponent.cs · VolumeParameter.cs
Subclass VolumeComponent and declare public readonly VolumeParameter fields. The base constructor discovers them by reflection, so blending, serialization, and editor UI all work for free.
FloatParameter · ClampedFloatParameterFloat, optionally clamped to [min,max] (slider in the editor).
IntParameter · ClampedIntParameter · BoolParameterInteger / clamped integer / boolean.
Vector3Parameter · ColorParameter · EnumParameter<T>Vector, color (HDR flag), and enum choices.
[Component(displayName: "My Effect")]
public class MyEffect : VolumeComponent {
    public readonly ClampedFloatParameter Intensity = new(1f, 0f, 2f);
    public readonly BoolParameter         Enabled   = new(true);
}

Inspector & serialization attributes

Decorate component fields and properties to control the editor and serialization. Public fields and read/write properties serialize and appear in the Inspector by default — these attributes refine that.

Editor attributes

Engine/Attributes/EditorAttributes.cs
[Range(float min, float max)]Render a numeric member as a clamped slider.
[Header(string)] · [Tooltip(...)] · [Space]Section label, hover tooltip, vertical spacing.
[HideInInspector]Hide from the Inspector but still serialize the value.
[NotSerialized]Exclude from both serialization and the Inspector — for runtime-only state (e.g. Rigidbody.Velocity).
[ReadOnly] · [SerializeField]Show but disable editing; explicit serialize marker (public fields already serialize — Unity parity).
[ColorUsage(bool hdr)]Render a Vector3 as a color picker (hdr allows values > 1).
[FoldoutGroup(string name)]Group members into a collapsible foldout.
[Button(string label)]On a parameterless method — render an Inspector button that calls it.
[Component(displayName, menu)]On a class — customize how it appears in the editor's Add Component menu.
