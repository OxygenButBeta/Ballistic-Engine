# GI Rework — root-cause analysis + phased plan (2026-06-14)

User verdict: the prior "Lumen-class multi-bounce" claim is **rejected**. Bounced light does not
scatter into rooms. This doc is the start-to-finish analysis + the rework plan. Anchored to the
PUBLISHED Lumen pipeline (Wright et al. SIGGRAPH 2021 "Radiance Caching for Real-Time GI"; SIGGRAPH
2022 Lumen course; Epic docs) — reimplement, never copy UE source.

## Empirical ground truth (headless isolated-bounce renders, this session)

Judge GI by the ISOLATED bounce (`BALLISTIC_SDFGI_DEBUG`), never the composite mean.

| Scene | Isolated-bounce result | Reading |
|---|---|---|
| **BistroInterior** (enclosed bar) | mean RGB **(0.7, 0.2, 0.1)**, only **~2% of pixels non-black**. Screen-trace off → 1.5%. | Bounce ≈ **zero**. Light does NOT scatter into the room. The world cache is nearly empty; the screen trace adds almost nothing. |
| **SunTemple** (open, sunlit) | mean RGB **(119, 102, 87)**, 100% non-black but **near-uniform**; screen-trace on/off nearly identical (119.3 vs 119.5). | A flat warm **wash**, not directional indirect. No "this wall is bright because the lit floor bounces onto it." |
| GDF warm-up | At frame 300 still **stuck at coarse 32³** (0.375 m cells), perpetually re-baking; the "96³" never materializes. | The distance field is permanently too coarse to represent an interior. ~4% gather-ray hit rate in the bar. |

Two failure modes, one root family: the per-pixel-gather-over-coarse-scalar-voxel-cache
architecture cannot produce smooth **directional** room-scale scattering.

## Root cause (verified against code)

1. **Real-Lumen path is gated OFF by default.** `BALLISTIC_LUMEN_GDF=1` is required; the default
   GI is the per-mesh brick path whose gather reads on-screen lit color as if it were diffuse
   irradiance → view-dependent, no off-screen scatter.
2. **Directionality is collapsed too early.** The voxel radiance clipmap stores **scalar** radiance
   per voxel (RGBA16F = one color, no direction), and the final gather is **6 noisy cosine rays
   averaged to one scalar** per half-res pixel. Far-field light carries no "arrives from this
   direction" → reads as a flat wash. The octahedral-probe path that fixes this is disabled (lattice).
3. **The directional signal that exists is diluted + starved.** Diffuse indirect is ADDED on top of
   a flat `AmbientFloor` + IBL baseline (a directionless veil that masks occlusion), throttled by
   per-frame amortization (96 injects/frame, 1 cascade/frame, sticky 0.75–0.9 EMA = 50–160 frame
   convergence), and halved by a 0.5 probe-coexistence scale.

Plus structural quality limiters: `ScreenTrace` runs to 4 m (mid-range view-dependent reprojection,
double-counts specular/emissive as diffuse); `MIN_ELEVATION=0.30` biases out grazing energy; glossy
reflection `mix`'d into the diffuse gather (inherits the diffuse denoiser → blurred); GatherBounce
step-starved for room scale; far voxels decay 0.5×/frame so room-center radiance evaporates.

## Keep / rework / replace / delete

- **KEEP** — GDF distance clipmap (`GLGlobalSdf` cascades/bake/warm-up); `MeshSdfBaker`;
  `SdfGi_Combine` (depth-aware upsample + per-pixel albedo rho + sky gate + NaN-select); the
  SSGI temporal + a-trous reuse for the DIFFUSE output.
- **REWORK** — voxel radiance clipmap → **directional** (6-axis / SH-L1 / oct per voxel) + light all
  visible cascades every frame; `ScreenTrace` → near-field only (~0.5 m); the octahedral screen-probe
  path → finer/adaptive placement + plane-distance interpolation that never zeros → make it default.
- **REPLACE** — per-pixel 6-ray scalar gather → octahedral probe gather; the glossy-in-diffuse mix →
  a dedicated specular-GI buffer + reflection denoiser; the flat `AmbientFloor` (remove when Lumen
  owns GI); the 0.5 probe-coexistence scale (→ single confident weight).
- **DELETE** — dead `HitRadiance()` in SdfTrace_Comp; the per-mesh brick path
  (`GLSdfAtlas`/`GLSdfScene`/`RadianceInject_Comp`) once the GDF path is the proven default.

## Phased plan (each phase: isolated-bounce verify on SunTemple+BistroInterior+CornellBox → commit)

**Order is deliberate: the room-scattering problem is fixed in Phases 0–2 before the big probe rework.**

- **Phase 0 — Honest GDF baseline + routing quick-wins (M, low risk).** Make the GDF path the
  default under test (keep env A/B back). Apply pure-routing quick-wins: clamp ScreenTrace to
  near-field (ST_MAXDIST 4.0→~0.5); remove `AmbientFloor` when `lumenOwnsGi`; remove the 0.5 probe
  scale. Capture deterministic isolated-bounce baselines (3 scenes). *Verify:* BistroInterior gains
  real off-screen fill vs near-black; SunTemple warmth becomes directional. **Rebuild the .exe** (shaders embedded).
- **Phase 1 — De-amortize the voxel cache (M, medium).** Inject ALL cascades every frame (drop the
  1-of-4 round-robin); looser/adaptive feedback (≈0.5–0.6 + stickier-when-static) → converge 2–4
  frames; fix far-voxel decay to preserve occupied interior voxels; raise bounceAlbedo clamp 0.55→~0.85;
  extend GatherBounce reach (STEPS→128–256, MAXD→cascade extent). *Verify:* frame-8 ≈ frame-240 on a
  static cam; BistroInterior room-center fill rises; no runaway (under the 32 cap).
- **Phase 2 — Directional voxel radiance (L, med-high).** Scalar → directional (6-axis chosen for
  cone-trace friendliness). Inject writes to the bin nearest the normal; gather/multi-bounce select
  the bin facing back along the ray. *Verify:* SunTemple isolated bounce becomes directionally graded
  (gradient toward the opening), not uniform; CornellBox bleed is direction-correct. **This kills the wash at its source.**
- **Phase 3 — Finer GDF near-field + cleaner sampling (L, medium).** Cascade-0 toward ~5–10 cm cells
  (raise Resolution to 128–160 OR lower BaseExtent to 6–8 m); bake at target res / mip chain instead
  of 32→128 upsample blur; remove `MIN_ELEVATION` after widening SELF_SKIP; schedule bakes by visible-
  cascade priority. *Verify:* corners between walls darken correctly (no leak across the gap); floors
  gain grazing fill; no first-load stall.
- **Phase 4 — Octahedral radiance probes as the final gather (XL, high).** Adaptive/finer placement
  (ProbeStep 8→4 + subdivide at discontinuities + per-block surface detection); 4×4 reconstruction
  with plane-distance weighting that never zeros; importance sampling toward last-frame-bright +
  BRDF lobe; make probes default, retire per-pixel. *Verify:* NO lattice on CornellBox/BistroInterior;
  lower noise at equal-or-lower cost; probes must MATCH then BEAT per-pixel before becoming default.
- **Phase 5 — World-space radiance backstop + separate reflections (XL, high; two sub-commits).**
  World-space octahedral radiance probe grid the screen-probe long rays interpolate from (distant +
  extra bounce). Dedicated specular-GI buffer + reflection-specific denoiser; remove gloss*0.5 mix.
  Composite diffuse + specular as separate HDR terms, no ambient floor. *Verify:* far-field stable
  directional bounce under pan; glossy floor near a red wall shows a SHARP red reflection; diffuse stays smooth.

## The north-star checklist (what makes it NOT a flat wash)

1. Directional radiance preserved end-to-end (surface cache → voxels → octahedral probes); collapse
   to scalar irradiance ONLY at the final per-pixel cosine integral. Any earlier collapse = wash.
2. Multi-bounce via surface-cache feedback (the enclosed bar fills because the cache re-gathers the
   voxel field each frame → many bounces). One bounce ≠ a lit room.
3. Off-screen light via the world-space caches (surface cache + voxels + world probes) — lamps behind
   pillars and sky through an opening contribute regardless of camera.
4. The trace fallback chain screen → mesh-SDF+surface-cache → voxel → sky gives the right radiance per
   distance band; the missing SDF+surface-cache link is what makes mid-range room bounce blotchy/leaky.
5. Adaptive ~16 px octahedral probes + importance sampling + temporal/spatial bilateral denoise =
   smooth low-noise diffuse at a tiny ray budget; a SEPARATE reflection trace keeps speculars sharp.
6. No ambient floor; HDR into exposure. Fill recesses with traced directional bounce; judge the
   isolated GI buffer; calibrate exposure independently.

If it still washes after this, the suspects, in order: (a) probes storing irradiance not octahedral
radiance, (b) no surface-cache multi-bounce feedback, (c) a residual ambient floor masking the signal.
